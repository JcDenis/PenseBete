Todos

This page keeps lists of things to do for this blog. They are shared by all the users of the blog who have the permission "manage todo lists". Nothing is shown on the public side of the blog.

New todo
The button "New todo" opens the form of a todo: say what there is to do in one line, choose its list, and add details if needed. Click on a todo of the list to edit it.
Lists
A list is a single word (letters, digits, "-" and "_"), for example blog or plugin. A list is created by adding a first todo to it, and disappears with its last todo. Without list, a todo goes to the list todo.
Status
A todo is "to do" or "done". The button at the end of each line changes it. Done todos are kept until they are deleted: use the filters to see them.
Filters and display options
By default the page lists the todos to do of all the lists. Filters limit it to a list, to a status or to a searched text, and display options set the sort and the number of todos per page. These options can also be set in your preferences.
Selected todos action
Check some todos to mark them as done or to do, to move them to another list, or to delete them. Deleting can not be undone.
Rename a list
The button "Rename a list" opens the form to give another name to a list. All the todos of the list follow. With the name of another existing list, both lists are merged.
Dashboard
In your preferences, add "Todo lists" to your favorites to have on the dashboard an icon giving the number of todos to do. In the dashboard options, you can also display there the last todos to do added, and choose how many.
